# 편명 데이터 출처

## Decisions

- 편명과 날짜로 공항과 예정 시각을 조회하는 데이터는 RapidAPI 마켓플레이스의 AeroDataBox 무료 Basic 플랜으로 가져옵니다.
- API 키는 서버 환경변수 `AERODATABOX_API_KEY`로만 읽고, 브라우저에 노출하지 않습니다. 로컬 값은 git에서 제외되는 `.env.local`에 둡니다.
- 무료 플랜의 조건인 AeroDataBox 출처 표기를 편명 데이터를 보여 주는 화면에 둡니다.
- 편명 데이터의 저장은 제공자 약관의 기간(기본 7일, 영구 복사본 금지) 안에서만 합니다. 저장한 지 7일이 지난 데이터는 보여 주지 않고 지웁니다.
- 저장 위치는 사용자의 브라우저 저장소입니다. 서버에는 편명 데이터를 저장하지 않습니다.
- 조회할 때마다 편명 데이터를 새로 가져온 뒤 그 결과를 저장합니다. 저장본은 조회를 대신하지 않고, 새 조회로 덮어씁니다.

## Boundaries

- aerodatabox.com에 직접 가입해 받은 키에는 무료 한도가 없으므로 이 결정에 해당하지 않습니다.
- 날씨 데이터 출처는 이 결정이 정하지 않습니다.

## Why

Google 검색은 서버 요청에 JS 안내 페이지만 돌려주고 약관상 긁어 쓸 수 없습니다. 키 없는 공개 경로(adsbdb)는 공항만 주고 예정 시각과 날짜가 없습니다. AirLabs 스케줄은 10시간 앞까지만 조회됩니다. AeroDataBox는 편명과 날짜로 미래 일정을 주고, 무료로 시작할 수 있는 곳은 마켓플레이스 플랜뿐입니다. API.Market 무료는 7일로 제한되어 RapidAPI를 택했습니다.

## Reconsider when

- RapidAPI 무료 Basic의 한도나 조건이 바뀌어 검증과 개발에 부족해질 때
- 직접 가입에 무료 한도가 생기거나 다른 서비스가 편명과 미래 날짜 조회를 무료로 제공할 때

## Still-rejected alternatives

- 직접 가입(aerodatabox.com) — 무료 한도 없이 월 19달러부터이고 실제 호출이 HTTP 402로 거절됩니다. 무료 한도가 생기면 다시 검토합니다.
- Google 검색 긁기 — 서버에서 편 정보가 오지 않고 약관에 맞지 않습니다.
- AirLabs 스케줄 — 최대 10시간 앞까지만 조회됩니다. 날짜 파라미터가 생기면 다시 검토합니다.
- 샘플 편명 데이터 — 실제 편명을 검증할 수 없습니다. 키를 쓸 수 없는 환경의 대체로만 남겨 둡니다.

## Evidence worth preserving

- RapidAPI의 `GET /flights/number/{편명}/{현지날짜}` 호출은 2일 뒤와 14일 뒤 날짜 모두 HTTP 200으로 응답했습니다. 응답은 배열이고, 각 항목에 출발·도착 공항(IATA, 좌표, 시간대)과 `scheduledTime`(UTC와 공항 현지 시각)이 있습니다.
- 직접 게이트웨이는 `https://api.aerodatabox.com/`와 `X-Api-Key` 헤더이며, 직접 가입 키로 호출하면 HTTP 402를 받았습니다. RapidAPI 주소에 직접 가입 키를 쓰면 HTTP 403이 왔습니다.
